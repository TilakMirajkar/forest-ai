# Forest AI
![CI](https://github.com/TilakMirajkar/forest-ai/actions/workflows/ci.yml/badge.svg)

An AI-powered journal API. Users write entries, rate their mood, and get
trends, weekly summaries, and reflective questions generated by a local LLM.
Entries never leave your machine.

## Features

- JWT authentication with Argon2 password hashing (OAuth2 password flow)
- Entries CRUD with per-user ownership enforced on every query
- Mood trends computed in SQL (`GROUP BY` day, `AVG`, `COUNT`)
- Weekly insights: entry counts, active days, best and hardest days
- Reflection prompts from a local model via Ollama, with mocked tests

## Tech stack

FastAPI, SQLAlchemy 2.0, Alembic, PostgreSQL, pydantic-settings, Ollama,
pytest, uv, Docker Compose, GitHub Actions.

## Quick start

Requirements: [uv](https://docs.astral.sh/uv/), Docker, and
[Ollama](https://ollama.com) with a model pulled.

```bash
git clone https://github.com/TilakMirajkar/forest-ai.git
cd forest-ai

cp .env.example .env          # then set SECRET_KEY to a long random string
docker compose up -d          # starts PostgreSQL
uv sync                       # installs dependencies
uv run alembic upgrade head   # creates the tables

ollama pull llama3.2
uv run uvicorn forest_ai.main:app --reload
```

Open http://127.0.0.1:8000/docs to try the API.

## Running tests

```bash
docker compose up -d
uv run pytest
```

The tests use the same PostgreSQL database and never call Ollama. The model
is replaced with a fake in the reflection tests.

## Project structure

```
src/forest_ai/
├── core/        # settings and security (hashing, JWT)
├── db/          # SQLAlchemy base and session
├── models/      # ORM models
├── schemas/     # Pydantic request and response models
├── routers/     # HTTP endpoints
├── services/    # AI client and prompt building, isolated from HTTP
└── deps.py      # shared dependencies (current user)
tests/           # pytest suite
alembic/         # database migrations
```

## Design notes

- **Ownership:** every entry query filters by `user_id`. A user requesting
  someone else's entry gets the same 404 as a nonexistent one.
- **Privacy:** the model runs locally through Ollama, so journal text is not
  sent to a third-party API.
- **Testability:** the AI call sits behind one function, so tests never need
  a running model.
